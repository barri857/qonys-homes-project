OPEN THE WEBSITE
1. Extract the entire project folder.
2. Open the folder in VS Code.
3. Open index.html using the Live Server extension.
Use Live Server so the property and translation JSON files can load.

FILES TO STUDY
Five HTML files: the page content and structure.
style.css: appearance, dark theme and mobile layout.
script.js: ordinary functions and jQuery event handlers.
properties.json: the apartment records.
translations.json: English, Russian and Kazakh text.
images: building covers and matching apartment galleries.
vendor: Bootstrap, jQuery and their licenses.

DEFENSE.txt gives the four-person demo plan and theory questions.
SOURCES.txt records the listing and image sources.

The property prices are dated Krisha asking-price snapshots.
Open the original ads for current prices and availability.
Viewing and contact forms save classroom demo requests only in this browser.
